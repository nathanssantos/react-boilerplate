# React TypeScript Boilerplate

Boilerplate for [React](https://react.dev/) applications with [MobX](https://mobx.js.org/) for state management, [Chakra UI](https://chakra-ui.com/) for components, and [Vite](https://vitejs.dev/) as the build tool.

## Tech Stack

- **React** with TypeScript
- **MobX** for state management
- **Chakra UI** for components
- **React Router** for routing
- **Formik + Yup** for form handling and validation
- **Axios** for HTTP requests
- **Vite** for fast builds and HMR
- **ESLint + Prettier** for code quality

## Getting Started

```bash
yarn install
yarn dev
```

## Build

```bash
yarn build
yarn preview
```
